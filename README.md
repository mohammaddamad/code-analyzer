# AI Code Analyzer | تحلیل‌گر هوشمند کد

**ابزاری مبتنی بر هوش مصنوعی برای تشخیص، توضیح و اصلاح خودکار خطاهای برنامه‌نویسی JavaScript**

پروژه AI Code Analyzer یک ابزار مبتنی بر JavaScript است که با هدف تشخیص، تحلیل، توضیح و کمک به اصلاح خطاهای برنامه‌نویسی توسعه داده شده است.

این پروژه با ترکیب ابزارهای تحلیل ایستای کد (Static Code Analysis) و یک مدل زبانی بزرگ (LLM) به نام Qwen2.5-Coder، کدهای JavaScript را بررسی می‌کند، مشکلات احتمالی را شناسایی می‌کند، علت خطاها را توضیح می‌دهد و نسخه پیشنهادی اصلاح‌شده کد را تولید می‌کند.

این سیستم از کتابخانه‌های Acorn و ESLint برای تحلیل کد و از Ollama برای اجرای محلی مدل هوش مصنوعی استفاده می‌کند.

---

## قابلیت‌های پروژه

- **تحلیل لغوی (Lexical Analysis):** شناسایی خطاهای رایج مربوط به توکن‌سازی کد JavaScript.
- **تحلیل نحوی (Syntax Analysis):** شناسایی خطاهای دستوری و ساختاری با استفاده از کتابخانه Acorn.
- **تحلیل معنایی و ایستای کد (Semantic and Static Analysis):** شناسایی مشکلاتی مانند متغیرهای تعریف‌نشده، متغیرهای استفاده‌نشده و دستورات غیرقابل‌دسترسی با استفاده از ESLint.
- **توضیح هوشمند خطاها (AI-Powered Error Explanation):** استفاده از مدل Qwen2.5-Coder برای توضیح خطاها و ارائه راه‌حل.
- **اصلاح خودکار کد (Automatic Code Fixing):** ترکیب قابلیت اصلاح خودکار ESLint و مدل Qwen برای تولید نسخه اصلاح‌شده کد.
- **اعتبارسنجی کد اصلاح‌شده (Code Validation):** بررسی مجدد کد تولیدشده با استفاده از Acorn و ESLint.
- **اجرای محلی هوش مصنوعی (Local AI Execution):** اجرای مدل زبانی روی سیستم شخصی از طریق Ollama، بدون نیاز به API Key یک سرویس هوش مصنوعی خارجی.

### توضیح اجزای اصلی پروژه

- **lexical.js:** انجام تحلیل لغوی کد با استفاده از Tokenizer کتابخانه Acorn.
- **syntax.js:** بررسی ساختار و قواعد دستوری JavaScript با استفاده از Parser کتابخانه Acorn.
- **semantic.js:** انجام تحلیل ایستای کد، شناسایی مشکلات و اعمال اصلاحات خودکار قابل انجام با ESLint.
- **ollama.js:** برقراری ارتباط با مدل محلی Qwen از طریق Ollama برای توضیح خطاهای شناسایی‌شده.
- **repair.js:** ارسال کد به مدل Qwen و دریافت نسخه پیشنهادی اصلاح‌شده.
- **server.js:** مدیریت درخواست‌های کاربران و هماهنگ‌سازی فرایند تحلیل و اصلاح کد.
- **index.html:** ایجاد رابط کاربری برای دریافت کد، نمایش نتایج تحلیل و ارائه نسخه اصلاح‌شده.

## نصب و راه‌اندازی پروژه

### ۱. پیش‌نیازها

برای اجرای پروژه به ابزارهای زیر نیاز دارید:

- Node.js (نسخه ۲۰ یا بالاتر توصیه می‌شود)
- npm
- Ollama

دانلود Ollama:

https://ollama.com/download

### ۲. دریافت پروژه از GitHub

```bash
git clone <repository-url>

cd AI-Code-Analyzer
```

به‌جای `<repository-url>` آدرس مخزن GitHub خود را قرار دهید.

### ۳. نصب وابستگی‌ها

در ترمینال و در پوشه اصلی پروژه دستور زیر را اجرا کنید:

```bash
npm install
```

### ۴. دانلود مدل هوش مصنوعی Qwen

برای دانلود مدل Qwen2.5-Coder از طریق Ollama دستور زیر را اجرا کنید:

```bash
ollama pull qwen2.5-coder:7b
```

### ۵. تنظیم متغیرهای محیطی

در پوشه اصلی پروژه یک فایل با نام `.env` ایجاد کنید و تنظیمات زیر را داخل آن قرار دهید:

```env
OLLAMA_BASE_URL=http://127.0.0.1:11434

OLLAMA_MODEL=qwen2.5-coder:7b
```

### ۶. آزمایش ارتباط با Ollama

برای اطمینان از برقراری ارتباط بین Node.js و مدل هوش مصنوعی، دستور زیر را اجرا کنید:

```bash
node test-ollama.js
```

در صورت برقراری ارتباط، پاسخ مدل در ترمینال نمایش داده می‌شود.

### ۷. اجرای پروژه

برای اجرای سرور دستور زیر را وارد کنید:

```bash
npm start
```

پس از اجرای موفق سرور، مرورگر را باز کرده و وارد آدرس زیر شوید:

```text
http://localhost:3000
```

## نحوه عملکرد پروژه

برنامه از دو فرایند اصلی تشکیل شده است:

### ۱. تحلیل کد (Code Analysis)

هنگامی که کاربر کد JavaScript خود را وارد می‌کند، مراحل زیر انجام می‌شوند:

1. کد از طریق رابط کاربری دریافت و به سرور Express ارسال می‌شود.
2. کتابخانه Acorn کد را از نظر خطاهای لغوی بررسی می‌کند.
3. در صورت موفقیت مرحله قبل، ساختار نحوی کد با Acorn بررسی می‌شود.
4. کتابخانه ESLint تحلیل ایستای کد را انجام می‌دهد.
5. کد و خطاهای شناسایی‌شده به مدل Qwen از طریق Ollama ارسال می‌شوند.
6. مدل هوش مصنوعی مشکلات احتمالی را توضیح می‌دهد و راه‌حل پیشنهاد می‌کند.
7. نتایج تحلیل به رابط کاربری بازگردانده و به کاربر نمایش داده می‌شوند.

### ۲. اصلاح خودکار کد (Automatic Code Fixing)

هنگامی که کاربر درخواست اصلاح خودکار کد را ارسال می‌کند، مراحل زیر انجام می‌شوند:

1. کد اولیه با استفاده از Acorn بررسی می‌شود.
2. ESLint اصلاحات خودکار قابل انجام را اعمال می‌کند.
3. خطاها و هشدارهای باقی‌مانده جمع‌آوری می‌شوند.
4. کد و گزارش خطاها برای مدل Qwen ارسال می‌شوند.
5. مدل هوش مصنوعی نسخه پیشنهادی اصلاح‌شده را تولید می‌کند.
6. کد تولیدشده مجدداً با Acorn و ESLint اعتبارسنجی می‌شود.
7. نسخه اصلاح‌شده و خلاصه تغییرات به کاربر نمایش داده می‌شوند.
8. کاربر می‌تواند کد پیشنهادی را بررسی کرده و در صورت تأیید، آن را جایگزین کد اولیه کند.

## نمونه عملکرد پروژه

فرض کنید کاربر کد JavaScript زیر را وارد کرده است:

```javascript
let x = 10;

console.log(y);
```

نتیجه احتمالی تحلیل:

- خطای لغوی: موردی شناسایی نشد.
- خطای نحوی: موردی شناسایی نشد.
- خطای تحلیل ایستا: متغیر `y` تعریف نشده است.
- توضیح هوش مصنوعی: متغیر `y` بدون تعریف قبلی مورد استفاده قرار گرفته است.
- پیشنهاد اصلاح: متغیر موردنظر را پیش از استفاده تعریف کنید.

مدل هوش مصنوعی همچنین می‌تواند نسخه پیشنهادی اصلاح‌شده کد را تولید کند.
